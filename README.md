## NumeriXa – Smart Multi-Calculator Web App

NumeriXa is a modern, responsive, and lightweight multi-calculator web application built with **HTML5, CSS, and  JavaScript**. It brings together a collection of practical calculators in a single, clean, and user-friendly interface, eliminating the need to visit multiple websites for everyday calculations. The project is designed with a glassmorphism-inspired UI, smooth navigation, and a mobile-first approach, making it comfortable to use on smartphones, tablets, and desktop computers.

The primary objective of NumeriXa is to create an all-in-one calculation platform that is fast, accessible, and easy to expand. Every calculator follows a consistent design language, providing users with a familiar experience across different tools.

### Project Vision

NumeriXa is continuously evolving into a comprehensive calculator ecosystem. Future updates will introduce additional finance, health, education, productivity, and utility calculators while maintaining the same intuitive user experience and consistent interface.

The project is developed as an open and practical front-end application, making it suitable for learning web development, experimenting with JavaScript logic, and building a scalable collection of useful everyday tools.

Whether you need quick calculations for school, work, business, or personal tasks, NumeriXa aims to provide a reliable, fast, and visually appealing solution from a single web application.

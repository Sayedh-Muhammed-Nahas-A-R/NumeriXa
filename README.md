# NumeriXa – All-in-One Calculator Hub

**NumeriXa** is a web-based, user-friendly calculator hub designed to provide a wide collection of useful calculators in one place. The project brings together mathematical, educational, financial, health, date/time, unit conversion, number system, and other specialized calculators through a single modern dashboard.

The main goal of NumeriXa is to make calculations simple, fast, accessible, and convenient without requiring users to install separate applications.

## 💱 Currency Converter

NumeriXa includes a dynamic currency converter that retrieves exchange-rate data from an online API. Users can select currencies, enter an amount, swap the source and target currencies, and view the converted value.

The currency converter is designed to support a wide range of international currencies instead of limiting users to only a few commonly used currencies.

## 🛠️ Technologies Used

NumeriXa is developed using standard web technologies:

- **HTML5** – Structure and content
- **CSS3** – Styling, responsive layout and glassmorphism effects
- **JavaScript** – Calculator logic and interactive functionality
- **REST API** – Live currency exchange-rate data

The project does not require a complex backend for the core calculators.

## 🎯 Project Objectives

The main objectives of NumeriXa are:

1. To provide multiple calculators through one web application.
2. To create a simple and user-friendly calculation platform.
3. To reduce the need for separate calculator applications.
4. To provide quick results with minimal user input.
5. To create a responsive web application suitable for different devices.
6. To practice and demonstrate HTML, CSS, and JavaScript development.
7. To create a useful real-world project that can be continuously expanded.
